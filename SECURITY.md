# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The LLM Security Gateway & Privacy Firewall project takes security seriously. If you discover a security vulnerability, prompt bypass, or privacy leak within this repository, please report it privately:

1. **Email:** Send details to `security@sentinel-gateway.dev` or directly to repository maintainers.
2. **Details to Include:**
   - Description of the vulnerability and attack vector (e.g., prompt injection payload, regex evasion, race condition).
   - Steps to reproduce with curl or Python sample script.
   - Proof of Concept (PoC) demonstrating bypass of security engine or policy rules.
   - Impact assessment (PII exfiltration, denial of wallet, tool privilege escalation).
3. **Response Timeline:**
   - Acknowledgement within 48 hours.
   - Severity triage and patch plan within 7 days.
   - Public disclosure coordinate following responsible disclosure guidelines.
